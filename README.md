# Computer Architecture Journey 🏛️⚙️

A rigorous, hands-on repository dedicated to mastering **Computer Architecture and Organization** from logic gates and instruction set architectures (ISA) up to memory hierarchies, pipelining, and multicore systems — aligned with top-tier university curricula (METU CENG & MIT 6.823 standards).

---

## 📚 Curriculum & Modules

- [ ] **01_Instruction_Set_Architecture_ISA:** Instruction formats, addressing modes, 2-operand vs 3-operand ISAs, register files, and low-level Assembly implementations (Selection Sort, string manipulation, recursion).
- [ ] **02_Computer_Arithmetic_ALU:** Fast addition (Carry-Lookahead), multiplication algorithms (Booth's Algorithm), division hardware, and IEEE 754 Floating-Point representation.
- [ ] **03_Datapath_And_Control:** Single-cycle vs multi-cycle processor datapaths, control unit design, microprogrammed control, state machine modeling.
- [ ] **04_Pipelining_And_Hazards:** Classical 5-stage RISC pipeline (IF, ID, EX, MEM, WB), structural hazards, data hazards & data forwarding, control hazards & branch prediction.
- [ ] **05_Memory_Hierarchy_And_Caches:** Locality of reference (spatial/temporal), direct-mapped vs set-associative vs fully-associative caches, write-through vs write-back, replacement policies (LRU, FIFO), 3C miss classification (Compulsory, Capacity, Conflict).
- [ ] **06_Virtual_Memory_And_Paging:** Virtual-to-physical address translation, multi-level page tables, Translation Lookaside Buffers (TLB), page fault handling, and page replacement algorithms.
- [ ] **07_Storage_And_IO_Systems:** Polling vs interrupt-driven I/O, Direct Memory Access (DMA), bus topologies, disk scheduling, and RAID storage architectures.
- [ ] **08_Parallelism_And_Advanced_Architectures:** Instruction-Level Parallelism (ILP), superscalar execution, out-of-order execution (Tomasulo), SIMD/Vector extensions, multi-core cache coherence (MESI protocol).

## 🛠️ Tools & Environments

- **Assembly & Emulation:** MARS / SPIM (MIPS), RARS (RISC-V), NASM / GCC (x86_64)
- **Simulators:** Logisim / Digital (gate-level & datapath), gem5 / SimpleScalar (architectural simulation)
- **HDL (Hardware Description):** Verilog / VHDL (hardware design & synthesis)
